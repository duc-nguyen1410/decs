## List of continuous parameters
Continuous parameters include inherent parameters of governing equations (e.g. `Ra`, `Pr`, ...) and following parameters:
- `Lx`: domain size in x-direction.
- `Ly`: domain size in y-direction (3D only).
- `Lz`: domain size in z-direction.
- `Aspect`: Aspect ratio of domain = $L_x/L_z = L_y/L_z$.
